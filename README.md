# Сайт для бронирования столиков в ресторане

## Описание

Этот проект представляет собой веб-приложение для бронирования столиков в ресторане.  Он позволяет пользователям просматривать информацию о ресторане, выбирать доступные столики на плане и делать бронирования онлайн. Ресторан может управлять информацией о столиках, а пользователи могут просматривать и отменять свои бронирования.

## Функциональность

*   Регистрация и авторизация пользователей.
*   Просмотр информации о ресторане (описание, адрес, телефон).
*   Выбор столика на плане ресторана.
*   Бронирование столика на определенную дату и время.
*   Добавление комментариев к бронированию.
*   Просмотр списка своих бронирований.
*   Отмена бронирования.
*   Управление информацией о столиках через админ-панель Django (для администратора).

## Установка

1.  **Клонируйте репозиторий:**

    ```bash
    git clone <your_repository_url>
    cd restaurant_booking_project
    ```

    (Замените `<your_repository_url>` на URL вашего репозитория)

2.  **Настройте Poetry:**
    *   Если у вас еще нет Poetry, установите его:
        ```bash
        curl -sSL https://install.python-poetry.org | python3
        ```
    *   Перейдите в директорию проекта и инициализируйте Poetry, если `pyproject.toml` не существует:
        ```bash
        poetry init
        ```
        Следуйте инструкциям, чтобы создать `pyproject.toml`.
    *   Установите зависимости проекта:
        ```bash
        poetry install
        ```
        Это также создаст файл `poetry.lock`, который гарантирует установку одних и тех же версий зависимостей.


3. **Настройте переменные окружения:**

    *   Создайте файл `.env` в корне проекта (опционально, если вы используете переменные окружения для чувствительных данных).
    *   Определите необходимые переменные (например, `DATABASE_URL`, `SECRET_KEY`).

4. **Соберите и запустите Docker Compose:**

    ```bash
    docker-compose up --build
    ```

    Эта команда скачает необходимые образы, создаст контейнеры и запустит приложение.

**Примените миграции:**

    После запуска контейнеров, выполните миграции Django для создания базы данных. Выполните следующую команду внутри контейнера `web`:

    ```bash
    docker-compose exec web python manage.py migrate
    ```

6. **Создайте суперпользователя:**

    Также внутри контейнера `web` создайте суперпользователя для доступа к админ-панели:

    ```bash
    docker-compose exec web python manage.py createsuperuser
    ```

    Следуйте инструкциям в командной строке для создания пользователя.
 
7. **Загрузка фикстур:**

    *   **Фикстуры** — это файлы с начальными данными для вашей базы данных.  
    * В нашем проекте они находятся в папке `restaurants/fixtures/` ).
    *   **Порядок загрузки:** Важно загружать фикстуры в правильном порядке, чтобы избежать ошибок, связанных с внешними ключами (Foreign Key constraints).  В данном случае, сначала нужно загрузить фикстуры, которые создают пользователей, а затем фикстуры, которые используют этих пользователей (например, ресторан).
    *   **Команды загрузки:**
        *   Убедитесь, что у вас созданы файлы фикстур (например, `accounts/fixtures/users.json`, `accounts/fixtures/initial_restaurant.json`, `accounts/fixtures/restaraunts.json`).
        *   Загрузите фикстуры, выполняя команды *внутри контейнера `web`*:

        ```bash
        # Загрузка пользователей и их профилей
        docker-compose exec web python manage.py loaddata restaurants/fixtures/users.json

        # Загрузка ресторана и столиков (которые ссылаются на пользователей)
        docker-compose exec web python manage.py loaddata restaurants/fixtures/initial_restaurant.json
        docker-compose exec web python manage.py loaddata restaurants/fixtures/restaurants.json
        ```

## Запуск

После успешной установки, приложение будет доступно по адресу `http://localhost:8000`.

*   **Админ-панель:** `http://localhost:8000/admin` (используйте учетные данные суперпользователя).
*   **Главная страница:** `http://localhost:8000/`

## Использование

1.  **Регистрация/Авторизация:** Создайте учетную запись или войдите в существующую.
2.  **Бронирование столика:** Перейдите на главную страницу, выберите столик на плане и забронируйте его на желаемую дату и время.
3.  **Просмотр бронирований:** Перейдите в раздел "My Bookings", чтобы просмотреть свои бронирования и отменить их при необходимости.
4.  **Управление рестораном (для администратора):** Войдите в админ-панель, чтобы управлять информацией о ресторане и столиках.
